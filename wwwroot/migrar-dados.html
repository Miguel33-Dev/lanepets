Trazer para o banco o que só existe neste navegador

O painel antigo guardava pets, agendamentos, serviços, produtos e lançamentos no localStorage deste navegador. Agora tudo vive no lanepets.db. Esta tela envia para o banco apenas os registros que ainda não estão lá.

Como funciona

1
Conferir — nada é gravado. O servidor compara cada registro com o banco e responde quantos são novos.
2
Importar — só então os novos são gravados. Registros que já existem são ignorados e nada do banco é sobrescrito ou apagado.
3
O localStorage continua intacto depois da importação, então dá para repetir a conferência quantas vezes quiser.

A comparação usa a identidade natural de cada registro: pet por (dono + nome), agendamento por (dono + pet + data e hora), produto por código, serviço por (nome + porte) e lançamento por (data + descrição + tipo + valor).
