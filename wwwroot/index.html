Como funciona

O LanePets não tem um cadastro de cliente separado: o tutor é criado automaticamente a partir dos dados informados aqui (nome, telefone e endereço). Se já existir um tutor com esses dados, o pet é vinculado a ele — nenhum cadastro duplicado é criado.

Para ver, editar ou remover tutores já cadastrados, use o módulo Clientes.
